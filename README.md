# CompTeq Digital Website

Professional website for CompTeq Digital, a Florida-based SaaS development company specializing in intelligent cloud applications.

## Overview

This is a modern, responsive website built with React and Tailwind CSS that showcases CompTeq Digital's expertise in:
- Custom SaaS Development
- Business Process Automation
- Data Analytics & Business Intelligence

## Technology Stack

- **Framework**: React 18+ with Vite
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Icons**: Lucide React
- **Build Tool**: Vite

## Features

- Fully responsive design
- Smooth scrolling navigation
- Interactive hover effects and animations
- Mobile-friendly hamburger menu
- Modern color scheme (blue and slate tones)
- Optimized performance

## Getting Started

### Prerequisites

- Node.js 18+ 
- pnpm (recommended) or npm

### Installation

```bash
# Install dependencies
pnpm install

# Start development server
pnpm run dev

# Build for production
pnpm run build

# Preview production build
pnpm run preview
```
